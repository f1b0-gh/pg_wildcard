# Contributing

Keep this package independently buildable with its own manifest and lockfile.
Preserve ClickHouse-compatible matching, raw values, sound pruning and bounded
input handling. Do not add unsafe code or production panics. Version format
changes and retain compatibility fixtures. Run default/all-feature tests,
formatting, strict Clippy, package verification and relevant integration tests.
Keep documentation in English and preserve license notices.

## Shared skills

Use [skills-dev](https://github.com/f1b0-gh/skills-dev) for relevant work:
`skills/rust-discipline/SKILL.md` for Rust policy, `skills/rust-skills/` for
selected Rust references, and `skills/clickhouse-sql/SKILL.md` for ClickHouse.
Read these in the shared repository or an installed copy; project contracts,
dependency constraints and validation commands take precedence over examples.
Keep maintained instructions and documentation in English.
